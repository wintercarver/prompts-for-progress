# Research workspace

This directory preserves the raw evidence and editorial reasoning used to construct the archive.

The initial search is **bounded near-exhaustive**, not absolutely exhaustive. Every research release should state its cutoff date, searched sources, query families, citation-chasing procedure, and known blind spots.

Candidates should remain in the register even when excluded, duplicated, or found to be unsupported. This makes the search auditable and prevents repeated rediscovery.

## Methods synthesis

The archive's periodic, cross-case prompt-method reviews live in [synthesis/prompt-methods/](synthesis/prompt-methods/README.md). Each dated summary is a point-in-time account of the available corpus; [the latest summary](synthesis/prompt-methods/LATEST.md) is the current empirical reference.

Reusable instructions are deliberately separate from the research record:

- [Cross-prompt methods synthesis playbook](../playbooks/cross-prompt-methods-synthesis.md) — for maintainers conducting a periodic corpus review.
- [Problem selection and prompt-design playbook](../playbooks/problem-selection-and-prompt-design.md) — for a researcher using the archive to design a local, problem-specific attempt.

Problem-specific working notes, scripts, and results do not normally belong in this directory. A shareable run can enter the archive only through the documented [submission workflow](../SUBMISSION_WORKFLOW.md).
