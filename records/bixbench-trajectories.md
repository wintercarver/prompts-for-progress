# BixBench publishes 2,120 bioinformatics trajectories

The benchmark contains 205 open-ended and multiple-choice questions derived from 60 published computational-biology notebooks and their data capsules. Tasks require data exploration, code execution, interpretation, hypothesis generation, and validation.

Its main value to this archive is methodological scale. Five-replica configurations and raw generated notebooks make it possible to study variance, refusals, execution errors, and apparent successes without reducing the campaign to a single leaderboard number.
