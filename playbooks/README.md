# Reusable research playbooks

These are stable reference instructions, not submitted research prompts and not records of a particular run. They live outside `prompts/` so that repository-authored guidance does not contaminate the historical prompt corpus.

- [Cross-prompt methods synthesis](cross-prompt-methods-synthesis.md) supports periodic, archive-wide reviews of methods and evidence.
- [Problem selection and prompt design](problem-selection-and-prompt-design.md) helps a researcher choose a tractable problem and prepare a fresh, domain-specific attempt.

The first playbook produces dated summaries under `research/synthesis/prompt-methods/`. The second is normally run in a separate local workspace. A completed attempt becomes part of this archive only if it is submitted through the [contribution workflow](../SUBMISSION_WORKFLOW.md).
